Bus Registration System Project - Description
The Bus Registration System is a web application built using ReactJS for managing buses, drivers, and routes effectively. It includes data validations, a user-friendly interface, and integration with REST APIs to perform CRUD operations.

Features
Bus Management

Add, update, and delete buses with relevant details like registration number, capacity, and assigned routes.
Display a dropdown of all buses with their registration numbers for easy selection.
Driver Management

Manage driver information, including name, contact number, and emergency contact.
Validations ensure contact numbers are exactly 10 digits.
Use a date picker for the driver's Date of Birth (DOB).
Drivers can be linked to specific buses.
Route Management

Add, update, and delete route details such as route name, start and end points, and stops in between.
Assign drivers and buses to specific routes.
Form Validations

Ensures all required fields are filled before submission.
Validates formats for fields like bus registration numbers, contact numbers, and route details.
Custom error messages for missing or incorrect input.
Integration with REST APIs

The application communicates with a backend server to handle bus, driver, and route data using REST APIs.
Functions include:
Fetch data: Load existing buses, drivers, and routes.
Create new entries: Save new buses, drivers, or routes.
Update existing records: Modify details of buses, drivers, or routes.
Delete records: Remove unused or outdated entries.
